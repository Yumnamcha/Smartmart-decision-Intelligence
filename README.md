## 📌 Overview

SmartMart Decision Intelligence is a comprehensive retail analytics platform that leverages **machine learning** and **data science** to transform raw sales data into actionable business intelligence. Designed to simulate real-world retail decision-making, this system empowers businesses with predictive insights and automated anomaly detection.

---

## ✨ Key Features

| Feature | Description |
|--------|-------------|
| 📈 **Sales & Profit Analysis** | Deep-dive into revenue trends and profit margins |
| 🔮 **Demand Forecasting** | Predict future sales using time-series and ML models |
| ⚠️ **Anomaly Detection** | Automatically detect unusual or fraudulent transactions |
| 🤖 **ML-Based Predictions** | Classification and regression for smart decision-making |
| 📊 **Interactive Visualizations** | Rich charts using Matplotlib and Seaborn |
| 🔍 **Exploratory Data Analysis** | Understand patterns, trends, and data distributions |

## 🚀 Getting Started

### Prerequisites
Make sure you have Python 3.8+ installed on your machine.

### 1. Clone the Repository
```bash
git clone https://github.com/Yumnamcha/Smartmart-decision-Intelligence.git
cd Smartmart-decision-Intelligence
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
python smartDI.py
```
